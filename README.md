# React Task Manager

A streamlined, responsive task management application built with **React.js**. This project is designed to help users organize their daily workflow with a clean, intuitive interface and real-time updates.

---

## 🌟 Features

* **Task Creation:** Quickly add tasks with a title and description.
* **Status Management:** Toggle tasks between "To Do", "In Progress" and "Done".
* **Persistent Storage:** Uses `localStorage` to ensure your tasks remain even after refreshing the page.
* **Responsive UI:** Fully optimized for mobile, tablet, and desktop screens.
* **Delete Functionality:** Easily remove tasks from your list.
* **Task Filtering:** Quickly narrow down your list or reorder tasks using built-in sorting and search parameters.

## 🛠️ Tech Stack

* **Frontend:** [React.js](https://reactjs.org/)
* **Styling:** CSS3 / Flexbox
* **Icons:** [FontAwesome](https://fontawesome.com/) or Heroicons
* **State Management:** React Hooks (`useState`, `useEffect`)
